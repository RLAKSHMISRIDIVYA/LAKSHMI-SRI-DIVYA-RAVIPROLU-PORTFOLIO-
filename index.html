MDR SENTINEL: HOSPITAL OUTBREAK INTELLIGENCE

Digital Twin IoT Sensors BLE Tracking Healthcare Outbreak Prevention

Overview: Designed and implemented as a Product Development Lab-2 project for the Computer Science & Engineering department in March 2026. This platform resolves modern clinical challenges where hospital disease tracking relies on slow paper files, resulting in late outbreak detection.

Project Context: Developed as part of SIH- 2025. We just built the preliminary website, didn't integrate anything yet, but were ready with the proposed plan and Architecture.

Key System Features:

  • Outpatient Movement Digital Twin: Replicates physical clinical structures in a digital environment to track movements and dwell times.
  • Real-Time Contact Tracing: Tracks high-risk exposure events using Bluetooth Low Energy (BLE) sensors worn by patients and healthcare workers.
  • Infection Replay Engine: Traces the patient pathway retroactively to identify exposure patterns and environmental contamination.
  • Predictive Analytics: Employs classification techniques to spot outbreak clusters before they spread to multiple wards.

GREEN: BIOMEDICAL WASTE SEGREGATION PLATFORM

React PostgreSQL Arduino Sensors AI Waste Classification Gamified SDGs

Overview: Designed and implemented as a Product Development Lab project for the Computer Science & Engineering department. This platform aims to optimize biomedical waste segregation and recycling efficiency in hospitals and healthcare settings.

Key System Features:

  • Intelligent Waste Classification: Classifies biomedical waste into Dry, Wet, Metal, and Hazardous categories using predefined rule-sets and image analysis.
  • IoT Smart Bin Prototyping: Integrated with physical Arduino-based hardware using moisture, metal, and IR/photoelectric sensors to automate segregation.
  • SDG-Based Gamification: Enhances staff compliance and training through interactive quizzes, games, and achievements linked to environmental Sustainable Development Goals.
  • Hospital Dashboard: Real-time visualization of segregation patterns, waste stats, and safety suggestions for healthcare environments.

AZURE DEMAND FORECASTER

Python ML React / Chart.js Flask API Time-Series Analysis

Overview: Developed as part of the Infosys Springboard Internship. This project builds a complete end-to-end Machine Learning pipeline to predict cloud resource demand (CPU, Storage, Active Users) and generate proactive capacity optimization insights.

Key Project Elements:

  • High-Accuracy Models: Achieved an overall forecasting accuracy of 84.7%, utilizing intelligently selected models per region (LSTM Deep Learning for complex patterns, XGBoost, and ARIMA).
  • Data Preprocessing & Feature Engineering: Merged Azure server telemetry datasets with holiday calendars and external markers, extracting rolling averages and lag values.
  • Capacity Risk Matrix: Compares 30-day predicted consumption against current hardware limits to classify regions into Red/Yellow/Green utilization risk zones.
  • Cost & Scaling Recommendations: Auto-generates actionable, ROI-driven resource scaling alerts (e.g., "Scale East US compute capacity by +150 units").
